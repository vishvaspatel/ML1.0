# Linear Regression Visualizer

A simple, educational Streamlit web application designed to help beginners visualize and understand the concepts of lines and simple linear regression.

## Features

- **Tab 1: y = mx + b Line Explorer**: Interactive sliders to adjust the slope (m) and intercept (b) of a line and see the visual effects instantly on a graph.
- **Tab 2: Simple Linear Regression**: An interactive tool to fit a linear regression model on a customizable dataset (CGPA vs. Placement LPA). It displays the learned equation, evaluation metrics (R-squared and MSE), a scatter plot with the fitted line, and allows making predictions based on your trained model.

## How to Run

1. Make sure you have Python installed.
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the Streamlit app:
   ```bash
   streamlit run app.py
   ```
