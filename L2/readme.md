# StudyPulse AI - Exam Score Predictor

This is a Streamlit web application that predicts an exam score based on the number of hours studied using a Linear Regression model.

## Prerequisites

Make sure you have Python installed. Then, install the necessary dependencies using the provided `requirement.txt` file.

## Installation

1. Navigate to the `L2` directory:
   ```bash
   cd "L2"
   ```

2. Install the required Python packages:
   ```bash
   pip install -r requirement.txt
   ```

## Running the App

To start the Streamlit application, run the following command in your terminal:

```bash
streamlit run app.py
```

The application will automatically open in your default web browser. If it doesn't, you can click on the `Local URL` provided in the terminal output (usually `http://localhost:8501`).
